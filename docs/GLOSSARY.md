# Glossary

**Bot / BotManifest** — persistent identity, policy preferences and model strategy. Identity does not include operative permissions.

**CAPT Core** — sole runtime, event persistence, execution admission, evidence, verification and claim authority in the intended composition.

**Cohort** — one participating model/analysis strategy. A vessel count does not automatically mean that many provider calls.

**Vessel** — distinct logical perspective within a cohort; not intrinsically a separately billed request.

**EventStore** — authoritative append-only event record maintained by Core; UI lists and cards are derived projections.

**HumanApproval** — Core-governed human decision boundary; neither an agent nor a Markdown instruction can silently grant it.

**DriverRun** — identity/state of a provider execution, whose external effect may require reconciliation.

**Indeterminate / reconciliation_required** — external outcome not established; check original evidence/identity instead of blindly retrying.

**Idempotency key** — stable operation identity used to prevent unintended duplicate effects where the API supports it.

**Mission / Goal** — durable objective with task lineage, not a guarantee that any worker is running.

**TaskNode** — Core-owned durable unit of work attached to a mission.

**Proposal** — compiled/selected operator objective before admitted execution; may need clarification and separate approval.

**Claim** — conclusion about work, subject to Core's verification authority; model output is not a self-verified claim.

**Locality policy** — preference/constraint for local or cloud handling; not a substitute for separate data and cost authority.

**R1–R4** — historical Bot-domain foundation, crew, Cloudflare and workflows tranches.

**R5 Convergence** — required semantic integration with modern CAPT Core and separately versioned Bot packaging; not yet complete.

**Stage-A gate** — historical test-process import overlay checking compatibility against a specific Core revision; not a production admission test.
